Forced Subtitles

Finds the foreign-language lines in a movie and writes a forced English subtitle (Movie.en.forced.srt) next to it, using the local Whisper service.

What to make
Subtitle languages (0 selected). English comes straight from Whisper; other languages are translated from it with NLLB-200, which adds about a minute per language for a full movie.
Detection
Speech in this language is never subtitled. Two-letter code, e.g. en.
Comma-separated codes, e.g. es, fr if you speak Spanish and French.
Leave empty to subtitle every foreign language.
Existing subtitles & audio track
Which audio track to listen to, in order, e.g. eng. Falls back to the default track.
Subtitle output
Lines containing these are removed. Common invented phrases like "Thanks for watching" are already dropped.
Library task & automation
Libraries (none ticked = all):

Run or schedule the task under Dashboard > Scheduled Tasks > Generate forced subtitles. It skips items it has already checked.

Service connection
Default: http://127.0.0.1:8796
Only needed if the service sees your files at different paths, e.g. D:\Movies => \\SERVER\Movies or D:\Movies => /media/movies.
Model & GPU
Don't use large-v3-turbo: it can't translate well.
NLLB-200 is free for personal, non-commercial use. With 3.3B on an 8 GB card, Whisper is unloaded while it translates.
